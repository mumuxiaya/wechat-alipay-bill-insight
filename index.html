微信 / 支付宝消费账单统计系统

上传微信支付账单和 / 或支付宝交易明细，自动合并退款、识别分类，生成净支出口径的图表与可下载的整理表格。
文件只在你的浏览器里解析，不会上传到任何服务器。

＋
拖入账单文件，或点击选择
微信 .xlsx / .csv，支付宝 .csv；可一次拖入多个，也可以分批导入
  • 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账，得到 xlsx。
  • 支付宝：我的 → 账单 → 右上角「…」→ 开具交易流水证明 → 用于个人对账，得到 csv。
  • 两个都传 = 合并汇总；只传一个 = 单平台分析，图表会自动适配。
  • 文件数量不限：重复上传同一个文件会自动跳过；日期范围更大的新账单会自动替换旧文件。
  • 已导入的文件会显示在顶部文件条里，点 × 可单独移除；想全部重来，点右上角「清空账单」。

提示：账单含敏感信息。本项目完全离线运行，无任何网络请求，数据也不落盘。
